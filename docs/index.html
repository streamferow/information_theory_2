◆ P - FLIP PROB

PROBABILITY THAT A TRANSMITTED SIGNAL (0 OR 1) WILL BE RECEIVED AS THE OPPOSITE VALUE. THIS IS A BIT INVERSION ERROR TYPE.

◆ M - ERASURE PROB

PROBABILITY THAT THE SIGNAL WILL BE SO CORRUPTED BY INTERFERENCE THAT IT CANNOT BE RECOGNIZED. THIS IS AN ERASURE EVENT.
